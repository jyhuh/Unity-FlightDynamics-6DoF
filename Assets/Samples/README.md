# FlightDynamics 6-DOF Test Scenes & Custom Assets

When opening `/Users/byabya/UnityDrone` in Unity Hub (`6000.3.11f1`):
1. Open the menu **`Tools > FlightDynamics 6-DOF > Engineering Workbench & Setup Wizard`**.
2. Go to **Tab 4 (`One-Click Scene Setup Wizard`)** and click **"Build Complete 6-DOF Flight Simulation Environment in Current Scene"**.
3. Save your test scene in this `Assets/Samples/` folder and press **Play**!
